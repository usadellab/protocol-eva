Title: Bacterial Transformation

Description:
This protocol explains how to transform a plasmid DNA template into competent bacterial cells which are then cultivated. The DNA is then purified from the cells using a miniprep kit.
The competent cells used in this protocol come from the NEB®10-beta Competent E. coli  kit. This protocol was adapted from the one provided with the cells.
