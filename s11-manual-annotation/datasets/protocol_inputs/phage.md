**2\. Sample preparation**

As more than four samples were included in the barcoding experiment, the recommended DNA input was **400 ng per sample**. For the volume calculations, the average concentration from the Qubit measurements was used.

BD\_R1 : 400 ng / 199.5 ng/µl = 2.01 µl

BD\_R2: 400 ng / 95.4 ng/µl = 4.19 µl

BD\_R3: 400 ng / 179.5 ng/µl = 2.2 µl

B\_R1: 400 ng / 106.1 ng/µl = 3.77 µl

B\_R2: 400  ng / 110.6 ng/µl = 3.61 µl

B\_R3: 400 ng / 133.6 ng/µl = 2.99 µl

As mentioned above, the Qubit measurements showed some variability. Therefore, the calculated sample volumes were rounded up to the next whole µL to ensure sufficient DNA input.

Two libraries were prepared per sample. One library was designated as the main sequencing library (1) , while the second was kept as a backup library (2) for reloading after flow cell flushing if the initial sequencing output was insufficient.
