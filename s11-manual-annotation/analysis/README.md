# Trend analysis of the same runs (branch `s11-trend-analysis`; additional material, not part of Supplement S11)

Question: which properties of an entry or of an answer are associated with the scores? Computed on the runs of the models of Table S11-2 only (the 10 model labels of `../results/v6/model_label_map.csv`); `trends.json`, `fig_trends.png` and every number below are computed from `../results/runs.csv` and `../results/entries.csv`. Population: prompt version 6, text only, manual annotation B, five entries, all these models for the descriptive parts; the permutation tests use the 8 models that cover all five entries (successful runs only). `../results/runs.csv` has one row per scored run of all prompts (431 runs incl. the PDF-text version of the spot assay), `../results/entries.csv` one row per entry, `failures_v6.json` the cause of every failed v6 run.
Columns: `cells_human` = cells in the manual annotation, `cells_ai` = cells in the answer, `rows_human` / `rows_ai` / `rows_aligned` = rows of the annotation, of the answer, paired rows, `steps_written` = protocols in the answer, `tables_human` = process tables of the annotation.

## How to run (from this folder, with main and this branch checked out together)
```
python3.13 analyze.py          # all tests -> trends.json   (numpy, pandas, scipy)
python3.13 make_figure.py      # -> fig_trends.png          (matplotlib)
python3.13 verify_trends.py    # second implementation of the headline statistics without scipy, prints ALL TREND STATISTICS CONFIRMED
```
`classify_failures.py` reads the run folders of the study (not part of the repository) and wrote `failures_v6.json`; `../scripts/build_run_table.py` wrote the two csv files. The tolerance of `verify_trends.py` is 1e-6, and 0.05 for the two pooled correlations of the unpaired-row share (the printed differences are the evidence). The permutation tests enumerate all 120 assignments of the cell-human values to the five entries; the bootstrap over models uses a fixed seed; `trends.json` and `fig_trends.png` are regenerated byte for byte.

## Result
| Observation | Statistic |
|---|---|
| Recall falls with cell human | mean per-model Spearman rho -0.64, 8 of 8 models negative, exact permutation p = 0.017 (the smallest p this test can give with 5 entries is 2/120); run level -0.11 recall per doubling of cell human, p = 0.008 (92 runs). Five entries differ in many attributes at once, so the observation is not attributed to annotation size alone. |
| Input length | rho -0.40 (characters, p = 0.300), -0.24 (words, p = 0.633); not significant with five entries, which is not evidence of no effect. |
| Precision and cell human | mean rho 0.41, p = 0.367. |
| Entry-level F1 | rank correlation of mean F1 with cell human -0.70 over 5 entries; the highest mean F1 is the bacteriophage sequencing entry; descriptive. |
| Unpaired answer rows and precision | within entry, rho -0.51 (383 runs of all prompts); 7 of 7 models negative, sign test p = 0.016; bootstrap over models -0.63 to -0.39. The share of unpaired rows comes from the same pairing that decides true and false positives, so part of this association is built into the metric. Pooled p-values in `trends.json` treat the runs as independent and are not used. |
| Recall and unpaired rows / extra steps | rho -0.13; more steps than annotation tables: recall rho 0.45, precision rho -0.23. |
| Text from the PDF instead of the HTML-derived text (spot assay, 5 models) | precision -0.12 (3 of 5 lower, Wilcoxon p not computed); recall -0.16 (4 of 5 lower, p not computed); `analyze.py` runs the Wilcoxon test only for more than five pairs, so there is no test with five models; descriptive. |
| Failed runs | 12% of the 120 v6 runs with text input (the 9 PDF-input runs of the spot assay are not counted); by entry spot assay 17%, bacteriophage sequencing 0%, strain generation 29%, BioLector cultivation 12%, plasmid generation 4%; rank correlation with cell human 0.70 (descriptive). |

Limits: five entries; the runs of one model are not independent (hence per-model tests, permutation over entries and bootstrap over models); the associations are correlational; the tests of recall and precision use successful runs only.
